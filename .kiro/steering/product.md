# Product Overview

## hyperpod-tui

A Terminal User Interface (TUI) based cluster manager for AWS HyperPod. This tool provides an interactive command-line interface for managing HyperPod clusters, offering a more user-friendly alternative to traditional CLI commands.

## Key Features
- Terminal-based user interface for HyperPod cluster management
- Interactive cluster monitoring and control
- Streamlined workflow for common HyperPod operations
