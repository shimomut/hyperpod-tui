# Product Overview

## hyperpod-tui

A Terminal User Interface (TUI) application for browsing and manipulating AWS SageMaker HyperPod clusters. This tool provides an interactive command-line interface for managing HyperPod clusters, offering a more user-friendly alternative to traditional CLI commands.

## Key Features
- Terminal-based user interface for SageMaker HyperPod cluster management
- Interactive cluster browsing and manipulation
- Cross-platform support (macOS, Windows, Linux)
- Real-time cluster monitoring and control
- Streamlined workflow for common HyperPod operations
